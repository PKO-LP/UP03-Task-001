## Этап 2. Объект ревью

Код ниже — учебный брак. Его не делать красивым до заполнения `REVIEW.md`.

```python
# src/module_dirty.py
# Учебный модуль учёта заявок. Не использовать в проде.

users = []

def add(n, e, a):
    users.append({"n": n, "e": e, "a": a, "id": len(users)+1})
    return True

def find(x):
    for u in users:
        if u["e"] == x or u["id"] == x:
            return u

def delete(i):
    for u in users:
        if u["id"] == i:
            users.remove(u)

def stats():
    s = 0
    for u in users:
        s = s + u["a"]
    return s / len(users)

def load():
    f = open("data.txt")
    for line in f:
        p = line.split(",")
        add(p[0], p[1], p[2])

if __name__ == "__main__":
    add("Иван", "ivan@", 20)
    add("Мария", "ivan@", "25")
    print(stats())
    delete(1)
    print(users)
```

ТЗ (сокращённо):

```
1. Учёт заявок: имя, email, возраст.
2. Email уникален.
3. Возраст — целое 1…120.
4. Поиск по id и по email раздельно.
5. Удаление только по id, с подтверждением.
6. Средний возраст считается только по валидным записям.
7. Файл data.txt читается в UTF-8, ошибки строк не роняют программу.
```
